# Contributing

Keep changes inside an existing component boundary unless the architecture documents and shared contracts change with them. Add or update a focused test before changing evaluation, retention, privacy, or persistence behavior.

Run the guardrail suite before proposing a change:

```bash
python3 tool/guardrails/guardrails.py all
```

Full workspace changes also require the pinned Flutter and Dart toolchain, analysis, package tests, and clean generated outputs. Use synthetic evidence only; never add resumes, interview recordings, credentials, or candidate records.
